# TrabarnetFilter — MVP

فیلتر محلی بارهای کامیون با CSV؛ این نسخه هنوز اتصال خودکار به TaraabarNet ندارد.

## اجرا (Windows 11 / Ubuntu)
1. Python 3.11+ نصب باشد.
2. در پوشه پروژه:
   ```bash
   python -m venv .venv
   ```
   فعال‌سازی:
   - Windows PowerShell: `.venv\\Scripts\\Activate.ps1`
   - Linux: `source .venv/bin/activate`
3. نصب و اجرا:
   ```bash
   pip install -r requirements.txt
   python app.py
   ```
4. مرورگر را روی http://127.0.0.1:5050 باز کنید.
5. فایل CSV را وارد کنید و فیلترهای مبدأ/مقصد، وزن، کرایه، ماشین و نوع بار را تنظیم کنید.

## ستون‌های CSV
ستون‌های فارسی یا انگلیسی قابل قبول‌اند. مبدأ و کرایه ضروری‌اند؛ سایر موارد اختیاری:
- مبدأ: `origin` یا `مبدأ`
- مقصد: `destination` یا `مقصد`
- وزن تن: `weight_ton` یا `وزن`
- کرایه تومان: `price` یا `کرایه`
- کامیون/بارگیر: `truck` یا `نوع کامیون`
- نوع بار: `cargo` یا `نوع بار`
- تلفن: `phone` یا `تلفن`

## نکته مهم
- این ابزار scraping، ورود به حساب، دور زدن محدودیت‌ها یا تماس خودکار با ترابرنت انجام نمی‌دهد.
- فقط داده‌هایی را وارد کنید که مجاز به ذخیره و پردازششان هستید. CSV جایگزین داده قبلی می‌شود.
- قیمت هر تن = کرایه تقسیم بر وزن (در صورت موجود بودن هر دو).
- داده در `data/loads.json` روی کامپیوتر شما نگهداری می‌شود.
